Khasra, khesra, gat, survey number: land-record terms of each state explained

BHU-NETRA Map Service · 20-10-2026

Every state calls the same things by different names. When you ask for a village map or a land record, using the local word saves a lot of back and forth. Here are the terms we meet every day.

Plot number

  • Khasra number - Rajasthan, Madhya Pradesh, Chhattisgarh, Uttar Pradesh (also gata), Haryana and Punjab (with killa / murabba), Delhi
  • Khesra (plot) number - Bihar
  • Gat / survey number - Maharashtra
  • Survey and hissa number - Karnataka; survey and sub-division number - Tamil Nadu, Goa
  • Survey number / LP (land parcel) number after resurvey - Andhra Pradesh
  • Plot number - Odisha; plot (dag) number - Tripura; re-survey / block and survey number - Kerala
  • Khata and plot number - Jharkhand; dag number - Assam; survey number - Telangana

Record of rights

  • Jamabandi - Rajasthan, Haryana, Bihar (with khata)
  • Khatauni - Uttar Pradesh, Uttarakhand; B-1 / khatauni - Madhya Pradesh, Chhattisgarh
  • 7/12 extract (satbara) - Maharashtra
  • RTC (pahani) - Karnataka
  • Patta / chitta - Tamil Nadu
  • Adangal / 1-B - Andhra Pradesh
  • Khata / RoR - Odisha
  • Khatian - Tripura, West Bengal
  • Form I & XIV - Goa
  • Thandaper - Kerala
  • Jamabandi (fard) - Punjab
  • Register II / khatiyan - Jharkhand
  • Jamabandi / chitha - Assam
  • Pahani / ROR-1B - Telangana

The unit above the village

Tehsil (most of north and central India), taluka (Maharashtra, Goa), taluk (Karnataka, Tamil Nadu, Kerala), mandal (Andhra Pradesh, Telangana), circle / anchal (Bihar, Jharkhand), circle and mouza (Assam), tahasil (Odisha). Below it, many states have a patwar halka, RI circle, hobli or firka.

Map names

Bhu-naksha / khasra naksha, shajra (UP, Haryana), mauza / mouza map (Bihar, Odisha, Tripura), village survey map, FMB sketch (Tamil Nadu, Kerala), land parcel map (Andhra Pradesh). Whatever the name, we deliver it as a georeferenced KML, DWG, SHP and Excel.
